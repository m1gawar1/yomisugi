# ヨミスギ

キーボードが壊れて、予測変換しか押せない。しかもこのスマホは予測しすぎる。
相手のメッセージに返信して、全部のエンディングを見つけるブラウザゲーム。

## ファイル構成

```
index.html              ゲーム本体（見た目と動き）。ネタの追加では基本さわらない
data/stages.json        ステージの並び順
data/stages/mom.json    ステージ1：お母さん
data/stages/boss.json   ステージ2：佐藤部長
scripts/check.mjs       データの自動チェック
CLAUDE.md               Claude Code 向けの作業ルール
```

## 手元で動かす

`index.html` をダブルクリックで開くと、ブラウザの制限でデータが読み込めません。
フォルダの中で次のどちらかを実行して、表示されたアドレスを開きます。

```
python3 -m http.server 8000     # → http://localhost:8000
npx serve                       # Node が入っている場合
```

## データのチェック

ネタを追加・修正したら、必ず実行します。

```
node scripts/check.mjs
```

行き先が切れた候補、たどり着けないエンディング、番号の間違いなどを見つけてくれます。

## ステージのデータの書き方

```json
{
  "id": "boss",                 ファイル名と同じにする
  "tab": "佐藤部長",            タブの表示名
  "who": "佐藤部長",            トーク画面の相手の名前
  "color": "#5b7bd5",           相手のアイコンの色
  "ask": "明日の会議資料できた？", 相手からの最初のメッセージ
  "askAt": "21:40",             その時刻
  "sentAt": "21:43",            返信した時刻
  "endings": [ ... ],
  "nodes": { ... }
}
```

**endings**（エンディング。上から END 01, 02 …）

```json
{"title":"模範解答","reply":"相手の返信","comment":"エンディングの一言","hint":"図鑑のヒント","good":true}
```

`good: true` は「普通に伝わった」エンディング（名前が緑で表示される）。

**nodes**（分岐）

```json
"s":  {"t":"","c":[["はい","h"],["すみません","m"]]},
"h":  {"t":"はい","e":19,"c":[["完成しています","h1"]]},
"h1": {"t":"はい完成しています","e":0}
```

- `s` はスタート地点。`t` は空にする
- `t` … その時点で入力欄に入っている文
- `c` … 予測変換の候補。`["表示する言葉", "行き先のノード名"]`
- `e` … その文で送信したときのエンディング番号（**0 から数える**。END 01 が 0）
- 途中の文で送ったときも何かのエンディングになるように、全ノードに `e` をつける

## 新しいステージを足す

1. `data/stages/` に新しい JSON を作る（既存のファイルをコピーすると楽）
2. `data/stages.json` の `order` に id を足す
3. `node scripts/check.mjs` でチェック
4. ローカルサーバーで遊んで確認

## GitHub Pages で公開する

1. GitHub にリポジトリを作って、このフォルダの中身を push する
2. リポジトリの Settings → Pages で、ブランチ `main`、フォルダ `/ (root)` を選んで保存
3. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で遊べる
